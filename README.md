# Study Hours Tracker

A beginner-friendly Python project that tracks weekly study hours and analyzes study patterns.

## Features

- Records daily study hours
- Calculates total study hours
- Calculates daily average
- Identifies the most and least productive study days
- Tracks weekly study goals
- Calculates goal progress
- Provides performance feedback
- Generates study-hours charts
- Saves data in CSV and JSON formats

## Technologies Used

- Python
- Pandas
- Matplotlib
- JSON
- Google Colab

## Project Purpose

This project was created to practice Python programming, data analysis, data visualization, and basic file handling.

## How It Works

The user enters study hours for each day of the week and sets a weekly study goal. The program analyzes the data and generates a performance report and visualizations.
